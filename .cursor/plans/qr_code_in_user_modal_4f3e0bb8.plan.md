# QR-код в модалке локального пользователя

## Ответ на вопрос

Да, это можно сделать: в React Native для Expo обычно подключают библиотеку отрисовки QR (например `react-native-qrcode-svg`, которая использует `react-native-svg`). Сейчас в проекте [package.json](d:\проекты\new\PERCo-C01-Manager\package.json) таких пакетов нет — их нужно добавить совместимыми с вашим SDK через `npx expo install react-native-svg react-native-qrcode-svg`.

## Формат payload (по вашему уточнению)

- Число идентификатора **укладывается в 3 байта (uint24)**: `0 … 16 777 215`.
- В QR кодируется **десятичная строка с ведущими нулями** на **10 символов**, например `16777215` → `0016777215`. Это попадает в «8–10 цифр» по смыслу отображения (фактически фиксированные **10** символов даёт единообразие для сканеров; при необходимости можно переключить константу на 8 для минимальной длины при том же числовом диапазоне).

## Изменения в UI

- Файл [components/modal-content/accessUserEditModal.tsx](d:\проекты\new\PERCo-C01-Manager\components\modal-content\accessUserEditModal.tsx):
  - Под полем «Идентификатор» (или блок «QR для прохода»): если после `trim` значение — **только цифры** и число в диапазоне uint24 — показывать компонент QR с `value={pad10(n)}`.
  - Если не число / вне диапазона — текст-подсказка вместо QR (например «Введите число 0–16777215 для отображения QR»).
  - Стили через существующую палитру [ThemeContext](d:\проекты\new\PERCo-C01-Manager\providers\ThemeContext.tsx) (фон модалки уже светлый/тёмный — при необходимости задать `color`/`backgroundColor` у QR под контраст).

- Вынести маленькие чистые функции в утилиту, напр. `utils/accessUserIdentifierQr.ts`: `parseUint24Identifier(s)`, `formatIdentifierForQr(n, digits = 10)`.

## Согласование с автоматической разблокировкой (важно)

Сейчас совпадение в [ControllerContext](d:\проекты\new\PERCo-C01-Manager\providers\ControllerContext.tsx) и кэше в [localAccessUsersDb](d:\проекты\new\PERCo-C01-Manager\utils\controller\localAccessUsersDb.ts) — **построчное** совпадение строк после `trim`. Если в БД записано `12345`, а сканер/контроллер шлёт в событии `0000012345`, совпадения не будет.

Рекомендуется в том же изменении (или сразу следом) расширить проверку для события `card`: если обе строки успешно парсятся как uint24, сравнивать **численно**, а не только посимвольно. Так QR (с ведущими нулями) и «короткая» запись в списке будут эквивалентны.

Опционально при сохранении в модалке **нормализовать** идентификатор к `pad10` для записи в SQLite — только если вы уверены, что PERCo всегда отдаёт именно такой же текст в `card.id`; иначе безопаснее оставить ввод как есть и полагаться на числовое сравнение в обработчике события.

## Краткий чеклист

1. `expo install react-native-svg react-native-qrcode-svg`.
2. Утилита парсинга/форматирования uint24 + строка для QR.
3. Блок QR в `AccessUserEditModal` по условию валидности.
4. (Желательно) Числовое сравнение `card.id` с разрешёнными идентификаторами при авторазблокировке.

## Риски

- Размер модалки на маленьких экранах — ограничить `size` QR (например 160–200 px).
- Нативная сборка: после добавления `react-native-svg` обычно нужен dev-client / prebuild, как и для других нативных модулей в проекте.
